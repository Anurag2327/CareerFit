# CareerFit — Resume & Job Match Analyzer

CareerFit is a full-stack web application that helps users analyze their resume against a job description and prepare for interviews.

## Features

- User registration and login
- Resume and job description analysis
- Job match score
- Skill gap identification
- Technical interview questions
- Behavioral interview questions
- Personalized preparation roadmap
- Interview plan management
- Delete interview plans
- PDF resume/report generation
- Protected user routes
- User-specific interview reports

## Tech Stack

### Frontend
- React.js
- JavaScript
- HTML5
- CSS3

### Backend
- Node.js
- Express.js
- REST APIs

### Database
- MongoDB
- Mongoose

### GenAI
- Google Gemini API

### Authentication
- JWT / Cookie-based authentication
